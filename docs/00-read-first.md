# Read First

This folder supplements the project's root `prd.md`.

## What `prd.md` owns

Product requirements and user-facing functionality: event map, sources, timeline, confidence, filters/search, phases and acceptance criteria.

## What this folder owns

Engineering constraints:

- architecture;
- module boundaries;
- data contracts;
- API contracts;
- security;
- scalability;
- responsive UX;
- testing;
- deployment;
- agent workflow.

The PRD already defines the core flow as `Article -> Event -> Location -> Map`, marker = event, multi-source provenance, timeline, confidence, and later Trend/TTS phases. Keep those product rules intact.
